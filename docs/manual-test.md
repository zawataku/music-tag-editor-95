# 手動テスト手順

画面まわりの確認手順。タグの読み書きそのものは `npm test` で確認できる。

## 準備

元に戻せなくてよい作業用フォルダを作り、各形式のファイルを入れる。
`test/fixtures/` の `blank.*`（タグ無し）と `broken.mp3`（壊れたファイル）をコピーしてもよいが、
実際の音楽ファイル（タグ・アートワーク付き）も混ぜる。

```
作業用/
  Album A/        MP3・FLAC（同じアートワーク付き）、ディスク 2 のサブフォルダ
  Album B/        M4A・OGG、壊れたファイル、タグ無しファイル
```

保存後の値は ffprobe で確認できる。

```
ffprobe -v error -show_entries format_tags:stream_tags -of compact=p=0 <ファイル>
ffprobe -v error -show_entries stream=codec_name,width,height:stream_disposition=attached_pic -of compact=p=0 <ファイル>
```

## 一覧

- [ ] ツールバー「フォルダ」→ 作業用フォルダを選ぶと、全ファイルが一覧に出る。タイトルバーにフォルダのパスが出る。
- [ ] ツールバー「開く」→ 複数ファイルを選ぶと、一覧が置き換わる。タイトルバーは「N 個のファイル」。
- [ ] 初期の並びが フォルダ → ディスク → トラック → ファイル名 になっている。
- [ ] 列見出しのクリックで昇順 ▲ / 降順 ▼ に並び替わる。見出しの境目のドラッグで列幅が変わる。
- [ ] クリック / Ctrl+クリック / Shift+クリック / Ctrl+A / 矢印キー（Shift で範囲）で選択できる。
- [ ] 壊れたファイルは灰色の行で、形式欄が「エラー」。マウスを乗せると理由が出る。
- [ ] エクスプローラーからファイルやフォルダをドロップすると追記される。同じファイルは増えない。
- [ ] ステータスバーが「N 個のファイル / M 個を選択 / 未保存 K」になっている。

## 詳細タブ

- [ ] 4 形式（MP3 / M4A / FLAC / OGG）それぞれで全項目を編集 → 保存 → 一覧を開き直して、同じ値が出る。
- [ ] 編集した行は太字になり、未保存の件数が増える。元の値に戻すと太字が消える。
- [ ] 複数選択で、値が違う欄は空欄に灰色の「(複数の値)」が出る。
- [ ] 複数選択で 1 欄だけ変えて保存すると、その欄だけが全ファイルで変わり、他の欄はファイルごとに元のまま。
- [ ] 欄を空にして保存すると、その項目が消える（ffprobe で確認）。
- [ ] 数値欄（年・トラック・ディスク）に数字以外が入らない。全角数字は半角になる。
- [ ] アーティストに `A;B` と入れて保存すると `A; B` と表示される。
- [ ] 一覧にフォーカスがある状態の Ctrl+Z（または ツールバー「元に戻す」）で、選択中のファイルの変更が消える。
- [ ] 何も選択していないとき、または壊れたファイルだけを選んだとき、全欄が灰色で入力できない。
- [ ] Alt+T / R / L / C / G / Y / M でそれぞれの欄に移る。

## 保存の失敗

- [ ] ファイルを読み取り専用にして（プロパティ →「読み取り専用」）編集・保存すると、
      その行が赤字になり「N 件のファイルを保存できませんでした。」とファイル名・理由が出る。他のファイルは保存される。
- [ ] 失敗したファイルの元のバイト列が変わっていない。`.〜.mte-tmp.〜` が残っていない。

## アートワークタブ

- [ ] 1 ファイルを選ぶと画像が枠の中央に出て、下に「幅 x 高さ ピクセル / 形式 / 容量」が出る。
      大きい画像は枠に合わせて縮小され、小さい画像は拡大されない。ウィンドウや分割線を動かすと追従する。
- [ ] 同じ画像のファイルを複数選ぶと、その画像が出る。違う画像だと「(複数のアートワーク)」で、書き出しが押せない。
- [ ] 画像が無いと「アートワークがありません」で、削除と書き出しが押せない。
- [ ] 追加 3 経路: 「アートワークを追加(D)…」で JPEG/PNG を選ぶ / 画像を枠へドロップ /
      画像をコピーしてアートワークタブで Ctrl+V。いずれも選択中の全ファイルに入り、太字になる。
- [ ] GIF や、拡張子だけ .png の別形式は「JPEG または PNG を指定してください」で拒否される。
- [ ] 10 MB を超える画像は確認が出る。「いいえ」で追加されない。
- [ ] 「削除(R)」（または枠を選んで Delete）で画像が消える。保存後、表紙以外の画像（裏表紙など）は残っている。
- [ ] 「書き出し(E)…」で保存ダイアログが出て、名前の初期値が「アルバム名.jpg（.png）」、アルバムが無ければ「cover」。
      書き出した画像が開ける。
- [ ] 保存後、エクスプローラーのサムネイルや他のプレーヤーでアートワークが見える。

## 終了・開き直し

- [ ] 未保存のまま × / ファイル > アプリケーションの終了 / Alt+F4 で「変更を保存しますか？」が出る。
  - [ ] キャンセル（または Esc）: 何も起きない。
  - [ ] いいえ（N）: 保存せずに終了する。
  - [ ] はい（Y）: 保存して終了する。保存に失敗したら終了しない。
- [ ] 未保存のまま「開く」「フォルダを開く」でも同じ確認が出る。
- [ ] 未保存が無ければ確認なしで終了する。

## タブ・メニュー・その他

- [ ] Ctrl+Tab / Ctrl+Shift+Tab でタブが切り替わる。一覧の選択を変えてもタブは変わらない。
- [ ] Alt+F / E / V / H でメニューが開く。灰色の項目は押せない。
- [ ] ファイル > エクスプローラーで表示 で、選択中のファイルがエクスプローラーで選ばれた状態で開く。
- [ ] ヘルプ > バージョン情報 に node-taglib-sharp / Electron のバージョンが出る。
- [ ] タイトルバーのドラッグで移動、ダブルクリックで最大化/元に戻す。

## 他のアプリでの見え方

- [ ] 保存した MP3 / M4A / FLAC をエクスプローラーのプロパティ（詳細）で開き、
      タイトル・アーティスト・アルバム・年・トラック番号・ジャンルが同じ値で見える。
- [ ] 複数ジャンル（例 `Rock; Pop`）の MP3 がどう表示されるかを記録する（既知の制限を参照）。
- [ ] iTunes / Music Center 等があれば、同じ値とアートワークが見える。

## 配布物

- [ ] `npm run dist:dir` が成功し、`dist/win-unpacked/Music Tag Editor.exe` が起動して、上の主要手順が動く。
- [ ] `npm run dist:win` のインストーラとポータブル版が起動する。
